# PaperClaw：面向公共管理学者的差异化功能分析

## 当前构想的核心模块
- personal research need：基于长期记忆形成对研究者议题、方法、偏好与阶段任务的持续理解
- literature corpus：结合用户自上传文献、导师/课题组专题文献库与外部数据库检索
- agent orchestration：围绕“研究问题—概念定位—文献证据—研究启发”形成回答链路
- output format：返回概念位置、研究用途、进一步建议与规范化回答- **internet access**：通过 Agent Reach 集成，提供全网语义搜索、网页内容提取、社交媒体数据获取等互联网访问能力
## 相比市面上通用 agent 的潜在差异化
### 1. 不是通用问答，而是“研究情境化”服务
多数 agent 只回答“这篇文献讲了什么”，PaperClaw 更像“理解这个学者正在做什么研究，再判断这篇文献为什么对 TA 有用”。

### 2. 不是单纯 RAG，而是“研究者画像 + 文献证据”的双层检索
市面上很多产品只基于知识库召回；你的构想把“用户长期研究需求”作为检索前提，这意味着同一个概念对不同研究者会返回不同的解释和用途。

### 3. 面向公共管理而非泛学科
公共管理研究有明显特点：
- 高度依赖概念辨析与理论脉络
- 重视政策情境、治理主体、制度背景
- 文献常跨公共管理、政治学、经济学、法学、社会学
PaperClaw 可以专门适配这些研究流程，而不是做通用型学术助手。

### 4. 强调“概念在文中的位置”而不仅是摘要
这点很重要。很多工具能总结文献，但不能快速告诉用户：某个概念具体出现在哪一部分、如何被定义、被如何操作化、在假设或结论中扮演什么角色。

### 5. 输出不是停留在检索，而是进一步服务研究设计
你的构想里有“对 personal research 的用处”“进一步建议”，这意味着它不只是找资料，而是帮助学者推进选题、变量构建、理论机制、研究设计与写作。

### 6. 可按导师/课题组/子领域构建专属知识边界
这和市面产品很不同。很多 agent 的知识边界是统一的，而你这里可以按不同老师、课题、团队维护不同文献池，更适合内部使用。

## 最值得突出的独特价值
### A. “概念—文献位置—研究用途”三联输出
这是非常清晰的产品特色，可以直接定义为核心功能链。

### B. “长期记忆驱动的个性化学术辅助”
不是记住用户偏好这么简单，而是记住：
- 用户长期关注的研究主题
- 当前论文阶段
- 常用方法
- 已经看过哪些文献
- 当前卡在哪个研究问题上

### C. “公共管理研究 workflow 嵌入式支持”
不是文献阅读工具，而是嵌入公共管理研究全流程：
选题 → 概念界定 → 理论梳理 → 文献定位 → 变量思路 → 机制假设 → 研究建议。

## 你这个项目最容易被低估、但其实很有竞争力的点
不是“能检索 Web of Science”，因为很多工具都能做；真正差异化的是：

**它知道用户为什么查这个概念、当前研究卡在哪里、以及这篇文献能如何进入用户自己的论文结构。**

## 后续可以继续细化的方向
### 1. 从“回答问题”升级为“研究任务模式”
可设计几种固定入口：
- 概念定位模式
- 文献综述模式
- 理论机制模式
- 研究设计启发模式
- 变量与测量模式

### 2. 强化“公共管理专属能力”
例如识别：
- 治理主体
- 政策工具
- 制度环境
- 问责机制
- 协同治理关系
- 政策执行链条

### 3. 加入“证据等级”与“文献角色”标注
例如区分：
- 概念定义文献
- 经典理论文献
- 实证支持文献
- 方法参考文献
- 争议/反向证据文献

### 4. 加入“与你当前研究的距离”判断
比如输出：
- 直接可用
- 可借鉴机制
- 可借鉴测量
- 仅作背景铺垫

## 一句话定位建议
PaperClaw 不是一个泛学科文献助手，而是一个**面向公共管理研究者、基于长期研究记忆与专属文献库、能够把“概念定位”直接转化为“研究推进建议”的内部学术 agent**。
