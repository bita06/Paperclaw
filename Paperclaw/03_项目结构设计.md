# PaperClaw 项目结构设计

## 技术栈选择

```
Backend:  FastAPI + Python 3.10+
ORM:      SQLAlchemy v2
Database: PostgreSQL (metadata + structure)
Vector:   Pinecone / Weaviate (embeddings)
Cache:    Redis
Search:   MongoDB (optional, for full-text)
Auth:     JWT + SQLAlchemy

Frontend: React + TypeScript (后续)
Async:    Celery + Redis (for background tasks)
Testing:  pytest + pytest-asyncio
Docs:     FastAPI auto docs (Swagger UI)
```

## 核心模块说明

### 1. `api/v1/` - API路由
- RESTful 端点
- 版本控制 (v1)
- 请求验证和响应序列化

### 2. `schemas/` - Pydantic模型
- 输入/输出数据验证
- 类型定义和文档

### 3. `models/` - SQLAlchemy ORM
- 数据库表定义
- 关系映射

### 4. `crud/` - 数据访问层
- Create, Read, Update, Delete 操作
- 数据库查询

### 5. `services/` - 业务逻辑层
- 复杂业务实现
- 第三方集成

### 6. `tools/` - 工具函数
- 向量数据库操作
- PDF处理
- NLP工具

## 开发工作流

1. 本地开发
   ```bash
   # 创建虚拟环境
   python -m venv venv
   source venv/bin/activate
   
   # 安装依赖
   pip install -r requirements-dev.txt
   
   # 设置环境变量
   cp .env.example .env
   
   # 运行迁移
   alembic upgrade head
   
   # 启动服务
   uvicorn app.main:app --reload
   ```

2. Docker开发
   ```bash
   docker-compose up -d
   docker-compose exec api alembic upgrade head
   ```

3. 测试
   ```bash
   pytest -v
   pytest --cov=app tests/
   ```
